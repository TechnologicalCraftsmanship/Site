# Como Executar o projeto
### 1. Clone o project ou baixe .zip

### 2. Acesse a pasta do projeto no terminal
```shell
cd site-diciplina
```

### 3. rodando o projeto
```shell
npm i
npm start
```

# se for necessário fazer build

### 4. Build
```shell
npm run build
```

### 5. Endereço do Site
